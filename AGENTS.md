# Datascience Admin

This app is a FastHTML + Faststrap admin PWA for the Segun Banji portfolio.

- Use Faststrap components first, Bootstrap utilities for structure, HTMX for interactions, and custom CSS only for admin polish.
- Keep Supabase service-role access server-side only.
- Preserve the public portfolio's black, gold, and off-white visual language.
- Keep mobile-first layout and verify that cards/forms/tables do not overflow on narrow viewports.
